# 검색·분류 품질 개선 설계 (2026-07-03)

## 배경

7월 3일 브리핑 검토 결과 다섯 가지 품질 문제가 확인됨:
관련 없는 기사 과다(분량 무제한), 요약 없음(Sonnet 모델 은퇴),
카테고리 오분류, 진보당→정의당 오분류, 정의당 소식 수집 부족.

## 결정 사항

1. **Sonnet 요약 복구**: `summarize.py`의 모델 ID를
   `claude-4-sonnet-20250514`(은퇴, 404) → `claude-sonnet-4-6`으로 교체.
2. **발송 기준**: 중요도 4점 이상만 섹션에 포함.
   기준값은 `config/keywords.yaml`의 `min_importance`로 설정화.
3. **점수 인플레 완화**: 신뢰 매체 가산을 0으로 (`trusted_boost: 0`).
   전체 기사의 82%에 적용되던 가산이라 변별력이 없었음.
   지역 +1(프롬프트)과 키워드 교차 +1은 유지.
4. **진보당 분리**: classify 프롬프트에 "진보당은 정의당이 아니다.
   기사에 '정의당'이 없으면 justice_party 분류 금지" 명시.
   allied_parties를 노동당·녹색당·진보당으로 확장.
   섹션 9를 "노동당·녹색당·진보당 동향"으로 개명하고 Phase 1에서 활성화.
5. **정의당 수집원**: 공식 RSS 없음(404 확인). 레고가 구글 알리미
   "정의당" 생성 후 feeds.yaml에 등록 (사용자 작업 대기).

## 예상 효과

- 브리핑 분량: 일 100건+ → 30~50건 수준
- 요약 대상 감소로 일일 비용 하락 (기존 월 $30 가드 유지)
